### About Me

I'm an embedded software engineer working at the layer where software meets
hardware. My work centers on firmware development, Embedded Linux, and
hardware-software integration — bringing boards up, writing drivers, and
debugging down to the signal level.

I care about reliability: clean abstractions, thorough testing, and systems
that behave the same on day 1000 as they do on day 1.
